# Matrice de Priorisation (MoSCOW)

| Fonctionnalité | Priorité | Justification |
| :--- | :--- | :--- |
| **Feed temps réel** | **MUST** | Cœur du projet. Sans ça, pas d'intérêt. |
| **Poster une demande** | **MUST** | Nécessaire pour alimenter le feed. |
| **Filtre par salle** | **SHOULD** | Important pour ne pas voir les demandes de l'autre bout de la ville. |
| **Profil avec Photo** | **COULD** | Aide à reconnaître la personne, mais un avatar couleur suffit pour la V1. |
| **Chat privé** | **WON'T** | Trop complexe, on gère ça à l'oral une fois regroupés. |
