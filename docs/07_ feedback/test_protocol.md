# Protocole de Test

**Tâche demandée à l'utilisateur :**
"Tu viens de finir ton échauffement. Utilise l'application pour signaler que tu vas faire du Développé Couché et que tu as besoin de quelqu'un pour t'assurer."

**Critères de succès :**
* L'utilisateur trouve le bouton "+" immédiatement.
* Il comprend qu'il doit sélectionner son exercice.
* Il ne se perd pas dans les menus.
